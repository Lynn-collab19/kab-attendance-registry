# KAB Student Attendance Registry

## 1. Project Overview

The **KAB Student Attendance Registry** is a simple attendance management application developed for **KAB**, an educational institution seeking to replace paper-based attendance sheets with a digital system.

The application allows administrators to register students, record daily attendance, track absences, calculate attendance rates, and identify students with chronic absenteeism.

The project was developed collaboratively by two students using **Git and GitHub** following a feature-branch development workflow.

---

## 2. Objectives

The main objectives of the project are to:

* Digitize student attendance records.
* Allow administrators to create and manage student profiles.
* Record students as **Present** or **Late** with timestamps.
* Automatically identify students who are absent.
* Calculate individual attendance rates.
* Identify students with attendance below 85%.
* Store attendance information using a local JSON file.
* Demonstrate collaborative software development using Git and GitHub.
* Practice feature branching, pull requests, code reviews, and merge conflict
